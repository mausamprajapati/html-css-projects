# Bento Grid Layout
A modern Bento Grid Layout built using HTML and CSS. This Project focuses on creating a clean, grid based UI.

## Technologies Used

- HTML 
- CSS 
- Grid
- Flexbox

## Features

- CSS Grid for page structure 
- Flexbox for content alignment
- Image  positioning using object-fit

## What I Learned

- Creating layouts with grid
- Combining Grid and Flexbox 
- Working with grid-column and grid-row
- Building modern Bento grid design
