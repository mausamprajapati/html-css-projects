# CSS card Hover Effect

A simple HTML and CSS project that demonstrates an interactive card hover effect using Flexbox and CSS transitions.

## Features

- Smooth hover animation
- Flexbox layout
- CSS transitions
- Clean and minimal UI

## Technologies Used

- HTML 
- CSS 
- Flexbox

## What I Learned

- Creating responsive layouts using Flexbox 
- Using CSS transitions for smooth hover animations
- Applying transform effects on hover 
- Using object-fit: cover for properly scaled images
- Structuring reusble card components with HTML and CSS
- Organizing project files and assests
- Managing projects with Git and GitHub
